# O que aprendi · Quiz SFPC

## 15/11/2026 · Do app de computador ao plano do APK

1. O Flet transforma o mesmo código Python em app de computador ou de Android: o que muda é o comando (`flet run` ou `flet build apk`).
2. Guardar as perguntas num arquivo dentro do app (o `quiz_cache.json`) é o que deixa ele funcionar sem internet, como um PDV que vende mesmo com a rede caída.
3. Gerar o APK no GitHub Actions evita instalar Flutter e Android SDK no computador, e em repositório público isso não custa nada.
